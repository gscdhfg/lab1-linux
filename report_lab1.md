#### Раздел 1. Перечень команд

> **`sudo su`**

**Назначение:** команда используется для получения прав суперпользователя (root). Позволяет выполнять административные действия в операционной системе.

**Параметры:**

- `sudo` — выполнение команды с правами суперпользователя;
- `su` — переключение на другого пользователя.

**Пример использования:**

```bash
sudo su
```

**Результат:** после выполнения команды пользователь получает права суперпользователя (root) и может выполнять административные действия в системе.

---

> **`sudo`**

**Назначение:** позволяет выполнять отдельные команды с правами суперпользователя.

**Пример использования:**

```bash
sudo apt update
```

**Результат:** указанная команда выполняется с административными правами.

---

> **`apt update`**

**Назначение:** обновляет информацию о доступных пакетах из подключённых репозиториев Ubuntu.

**Параметры:**

- `update` — обновляет информацию о доступных пакетах.

**Пример использования:**

```bash
apt update
```

**Результат:** система получает актуальную информацию о доступных пакетах и их версиях.

---

> **`apt install ssh`**

**Назначение:** устанавливает пакет `ssh`, необходимый для организации удалённого доступа к Linux-системе.

**Параметры:**

- `install` — установка указанного пакета;
- `ssh` — название устанавливаемого пакета.

**Пример использования:**

```bash
apt install ssh
```

**Результат:** в системе устанавливается SSH, после чего становится возможным удалённое подключение к компьютеру.

---

> **`apt install mc`**

**Назначение:** устанавливает файловый менеджер Midnight Commander.

**Параметры:**

- `install` — установка пакета;
- `mc` — название пакета Midnight Commander.

**Пример использования:**

```bash
apt install mc
```

**Результат:** в системе устанавливается файловый менеджер `mc`.

---

> **`mc`**

**Назначение:** запускает файловый менеджер Midnight Commander для работы с файлами и каталогами в консольном интерфейсе.

С помощью `mc` можно:

- просматривать содержимое каталогов;
- копировать файлы;
- перемещать файлы;
- удалять файлы;
- создавать каталоги;
- подключаться к удалённым компьютерам.

**Пример использования:**

```bash
mc
```

Для подключения к удалённой системе используется меню:

```text
F9 → Left/Right → Shell link...
```

**Результат:** открывается двухпанельный файловый менеджер Midnight Commander.

---

> **`ip a`**

**Назначение:** используется для просмотра сетевых интерфейсов и IP-адресов компьютера.

**Параметры:**

- `ip` — команда для просмотра и настройки сетевых параметров;
- `a` — сокращение от `address`, вывод информации об адресах сетевых интерфейсов.

**Пример использования:**

```bash
ip a
```

**Результат:** отображается информация о сетевых интерфейсах компьютера, включая назначенные IP-адреса.

В лабораторной работе данная команда используется для определения IP-адресов основной и виртуальной машин.

---

> **`ssh пользователь@IP-адрес`**

**Назначение:** используется для удалённого подключения к другому компьютеру по протоколу SSH.

**Параметры:**

- `пользователь` — имя пользователя удалённого компьютера;
- `IP-адрес` — адрес удалённого компьютера;
- `-p` — позволяет указать порт для подключения;
- `-v` — включает подробный вывод информации о процессе подключения.

**Пример использования:**

```bash
ssh user@192.168.1.2
```

Пример с указанием порта:

```bash
ssh -p 22 user@192.168.1.2
```

**Результат:** после успешного подключения пользователь получает возможность удалённо работать с командной строкой Linux.

---

> **`ls`**

**Назначение:** используется для просмотра содержимого текущего каталога.

**Основные параметры:**

- `-l` — вывод подробной информации о файлах и каталогах;
- `-a` — отображение скрытых файлов;
- `-la` — отображение всех файлов, включая скрытые, в подробном формате.

**Примеры использования:**

```bash
ls
```

```bash
ls -l
```

```bash
ls -la
```

**Результат:** на экран выводится список файлов и каталогов текущей директории.

В лабораторной работе команда `ls` используется для просмотра содержимого каталогов и подготовки файла для обмена между основной и виртуальной машинами.

---

> **PuTTY**

**Назначение:** PuTTY — приложение для удалённого подключения к компьютерам. В лабораторной работе оно используется для подключения из основной операционной системы Windows к виртуальной машине с Linux по протоколу SSH.

**Алгоритм работы:**

1. Запустить приложение PuTTY.
2. В поле **Host Name (or IP address)** указать IP-адрес виртуальной машины.
3. В поле **Port** указать порт SSH — `22`.
4. Выбрать тип подключения **SSH**.
5. Нажать кнопку **Open**.
6. При первом подключении подтвердить ключ сервера.
7. Ввести имя пользователя Linux.
8. Ввести пароль пользователя.

**Результат:** после успешной авторизации открывается командная строка Linux, через которую можно удалённо выполнять команды на виртуальной машине.

---

Для организации сетевого соединения между основной и виртуальной машинами в Oracle VirtualBox необходимо выбрать режим **«Сетевой мост» (Network Bridge)**.

После настройки сетевого соединения IP-адрес виртуальной машины определяется с помощью команды:

```bash
ip a
```

Для обмена файлами между основной и виртуальной машинами используется файловый менеджер `mc`. Подключение к удалённой системе выполняется через меню:

```text
F9 → Left/Right → Shell link...
```

Для просмотра содержимого каталогов и проверки файлов используется команда:

```bash
ls
```
